# Tetris de Sonia

Tetris para jugar en el móvil o en el ordenador, en un único `index.html`.

**Jugar:** https://pedritogrillo.github.io/tetris-de-sonia/

## Controles
- Botones táctiles: ← → mover, ↻ girar, ↓ bajar, ⤓ caída rápida. Tocar el tablero también gira.
- Teclado: flechas, ↑ o X para girar, espacio para caída rápida, P o Esc para pausa, Enter para empezar.

El récord se guarda en el navegador.
